# HCMUS Hub v0.8.5 — CTSV content display

## Symptoms
Some CTSV notices show a listing excerpt and then the same opening sentences again as the complete body. A subset also contains literal entity text such as `&nbsp;`.

## Changes
- Dashboard compares normalized summary/body prefixes and omits only a long summary that is a clear duplicate of the body opening. Independent summaries continue to display.
- A bounded repeated-entity decoder handles double-escaped HTML entities while preserving paragraph/newline layout for API body text.
- Rich HTML sanitization decodes text nodes only; it does not decode attributes, URLs, or markup before sanitizing.
- API response normalization fixes legacy database text at display time without migrating or rewriting the SQLite database.

## Validation
Run the project test suite from the project root with `python -m pytest -q`.
